# 构建与签名

## 签名配置

签名材料不进仓库：keystore 与口令只存在于 GitHub Secrets 和发版机器上。

| 位置 | 用法 |
|---|---|
| CI | Secrets：`KEYSTORE_BASE64` / `KEYSTORE_PASSWORD` / `KEYSTORE_ALIAS` / `KEY_PASSWORD`，构建前还原到 `keystore/`，随 runner 销毁 |
| 本地 | 环境变量 `KEYSTORE` / `KEYSTORE_PASSWORD` / `KEYSTORE_ALIAS` / `KEY_PASSWORD`，keystore 放仓库外（如 `~/.keys/`） |

固定证书 SHA-256：`05:D1:26:5D:87:0C:5B:72:E5:3C:8A:74:5D:BE:8F:E1:2E:DB:79:1E:A1:7F:7B:DA:F4:02:34:90:4C:4D:50:57`。
`build-apk.sh` 会核对这个指纹，不一致直接失败。

> **历史提示**：该 keystore 在 2026-11 之前曾随公开仓库提交，私钥应视为已泄露。为保住已安装用户的覆盖升级，暂不轮换；轮换需走 APK v3 密钥轮换或换包名迁移。

## 构建命令

```bash
export KEYSTORE=~/.keys/zichuan-release.jks
export KEYSTORE_PASSWORD='…' KEYSTORE_ALIAS=zichuan KEY_PASSWORD='…'
bash build-apk.sh
```

产物：`dist/zichuan-assistant-<VERSION_NAME>.apk`

## 环境变量

```bash
KEYSTORE=~/.keys/zichuan-release.jks \
KEYSTORE_PASSWORD=xxx KEYSTORE_ALIAS=zichuan KEY_PASSWORD=xxx \
bash build-apk.sh
```

密码不落盘、不打印，只通过环境变量传给构建脚本；CI 里不要用 `bash -x`，否则会把口令打进日志。

## 验证签名

```bash
/home/you/android-sdk/build-tools/36.0.0/apksigner verify --print-certs dist/zichuan-assistant-*.apk
```

## 版本号规则

- 覆盖安装要求 `versionCode` 大于已装版本
- `app/pubspec.yaml`：`version: 2.0.0+1`（versionCode 1）
- 私有脚本默认 `VERSION_NAME=2.0.0`，`VERSION_CODE` 留空时自动生成
