# 构建与签名

## 签名配置

本仓库自带固定 release keystore：`keystore/zichuan-release.jks`

- 别名：`zichuan`
- 算法：RSA 2048
- 有效期：10000 天（至 2054-04-07）
- 证书 SHA-256：`05:D1:26:5D:87:0C:5B:72:E5:3C:8A:74:5D:BE:8F:E1:2E:DB:79:1E:A1:7F:7B:DA:F4:02:34:90:4C:4D:50:57`

## 构建命令

```bash
cd /root/zichuan-android/repo
bash build-apk.sh
```

产物：`dist/zichuan-assistant-<VERSION_NAME>.apk`

## 环境变量

```bash
KEYSTORE_PASSWORD=xxx KEY_PASSWORD=xxx bash build-apk.sh
```

密码不落盘、不打印，只通过环境变量传给构建脚本。

## 验证签名

```bash
/root/android-sdk/android-14/apksigner verify --print-certs dist/zichuan-assistant-*.apk
```

## 版本号规则

- 覆盖安装要求 `versionCode` 大于已装版本
- `app/pubspec.yaml`：`version: 2.0.0+1`（versionCode 1）
- 私有脚本默认 `VERSION_NAME=2.0.0`，`VERSION_CODE` 留空时自动生成
